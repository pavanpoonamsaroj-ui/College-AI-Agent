# 🎓 College AI Agent

An all-in-one AI-powered assistant built for college students to help manage assignments, summarize study material, generate flashcards, and answer project-related questions using Google's Gemini API and ChromaDB.

---

## 🚀 Features

* **Ask PDF / Documents:** Upload study materials or assignments and get instant, context-aware answers.
* **Smart Summarizer:** Quickly condense long readings, lecture notes, or research papers into concise key points.
* **Flashcard Generator:** Automatically turn your notes or documents into interactive flashcards for studying.
* **Quiz & Assignment Help:** Get tailored assistance, explanations, and step-by-step guidance for your college projects and coursework.

---

## 🛠️ Tech Stack

* **Python** (Core logic)
* **Streamlit** (Web UI framework)
* **Google GenAI SDK** (`google-genai` with Gemini Flash models)
* **ChromaDB** (Local vector database for document context)
* **PyPDF** (PDF text extraction)
